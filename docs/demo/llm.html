agent-gate's LLM gateway, step by step

A replay of a real run of the LLM gateway with the example config, in front of the fake provider from the tests: a call routed to a cheaper model, a secret stopped before it leaves, a call refused by its budget, a streamed answer held until it has been read, and the books checked at the end. Each step shows what the agent sent and got back, whether anything reached the provider, what was written down, and the code that decided. The MCP gateway has a replay of its own.
